# isu-ai-portfolio

AI 활용·프롬프트 코칭 포트폴리오. 빌드 없는 정적 페이지 3장.

- `index.html` — 랜딩. 공고 직무 3줄에 1:1 매핑
- `report-demo/` — 공정 실적 엑셀 업로드 → 주간 요약·이상치 리포트 (샘플 데이터는 전부 가상)
- `prompt-guide/` — 직군별 프롬프트 코칭 + AI 보안 수칙 원페이지
- 로컬 실행: 각 `index.html`을 브라우저로 열면 끝 (빌드 없음)
- 수정 후 main에 push하면 GitHub Pages에 반영
- 썸네일 재생성: 각 배포 URL을 1280×800으로 캡처해 `assets/*.webp` 교체
