① 사내 AI 교육 및 프롬프트 코칭 경험

AI 활용법 사내 교육 경력

EDM유학센터와 종로유학원 두 곳에서 사내 교육을 맡아 왔습니다. 종로유학원에서는 매니저들을 상대로 AI 활용 교육을 직접 만들어 진행했습니다. 상담 업무별 활용법과 시연으로 구성했고, 마지막 장은 개인정보 가명 처리, 내부 자료 업로드 금지 같은 보안 수칙이었습니다. EDM유학센터에서는 학생들의 출국 준비 안내를 담당하며, 처음 듣는 사람에게 같은 절차를 반복해 설명했습니다. 듣는 사람이 매니저든 학생이든 아는 만큼이 다 다르다는 전제로 말을 고르는 일에 익숙합니다.

그 교육의 뼈대인 업무별 활용법과 보안 수칙을 이 공고의 직군에 맞춰 새로 쓴 것이 직군별 프롬프트 가이드입니다. 생산관리, 품질, 사무지원 세 직군의 나쁜 예와 좋은 예 카드 9장에, 실제 값을 [A사], [00%]로 치환해 쓰는 보안 수칙까지 한 페이지에 담았습니다. 입사하면 첫 배포물로 바로 쓸 생각으로 만들었습니다.

② 현업 요구사항 기반 AI 기능 개발

요구사항을 기다리는 대신, 이 공고에 적힌 업무로 시제품을 먼저 만들었습니다.

같은 공고의 생산기획 직무에 공정 실적 관리와 데이터 분석 업무가 있습니다. 그 업무를 가정하고, 라인별 실적 엑셀을 올리면 주간 요약과 이상치 하이라이트가 나오는 리포트를 만들었습니다.

  • 이상치 판정 기준을 페이지에 그대로 적어, 표시된 값은 손으로 재검산할 수 있습니다
  • 업로드한 파일은 서버로 가지 않고 브라우저 안에서만 처리됩니다
  • 샘플 데이터는 전부 가상입니다
  • 검산할 수 있어야 하는 수치 판정은 고정 규칙에 맡기고, AI는 개발 단계(Claude Code)에 썼습니다

같은 순서로 마친 기록: 조사 → 검증 → 구현 → 배포

③ AI 활용 및 관리

도입 효과는 건별 기록으로 남기고, 결과물은 사람이 검증합니다.

자동화 대상사용 도구Before → After효과
콘텐츠 제작 표준화 (카드뉴스·블로그·쇼츠) Claude 스킬 3종 + Playwright 렌더링 Before → After건당 2~4시간 → 30분~1시간 절감누가 해도 같은 품질

검증: 발행 전에 수치와 날짜를 원문과 대조하고, AI 문형을 걸러내는 검수 단계를 거칩니다. 카드뉴스, 블로그, 쇼츠 그래픽을 각각 스킬로 고정해 두어 작업 방식 자체가 문서로 남고, 인수인계가 됩니다.

국가별 안내 사이트 데이터 구축·배포 Claude Cowork (AI 리서치·교차검증) + Claude Code (구현) Before → After수작업 3일 → 4~5시간 절감사이트 5종 배포

검증: 수집한 데이터를 각 학교 공식 페이지와 대조해 확인한 뒤 반영했습니다. 영국, 미국, 호주, 캐나다 4개국 대학과 컬리지 259곳을 수록했습니다. Cowork로 조사하고 Claude Code로 구현해 GitHub Pages에 배포했습니다. 허브까지 5종입니다.

반복 안내 셀프서비스화 Notion 시스템 (영국·캐나다·호주) Before → After구두 안내 1시간/건 → 셀프 안내 절감건당 40분

검증: 읽는 사람이 스스로 확인하고 질문만 상담으로 남겨, 건당 확인 시간은 20분 수준으로 줄었습니다. 매번 1시간씩 구두로 반복하던 안내를 국가별 Notion 문서 체계로 코드 없이 표준화해, 안내 누락을 구조적으로 방지합니다.

커스텀 스킬은 자연어 지침으로 만든 자동화 모듈입니다. 코드를 몰라도 만들고 고칠 수 있습니다. 이런 스킬을 약 20종 운영하며 반복 업무를 고정해 두었습니다. 작업이 스킬로 남으면 담당자가 바뀌어도 같은 품질이 나옵니다. 사내 AI 활용을 표준화하고 관리하는 일에 그대로 옮겨 쓸 수 있는 방식입니다.

검증은 사람이 합니다. 오류 하나가 결과를 바꾸는 서류를 건별 마감과 체크리스트로 관리해 온 기준을 AI 산출물에도 그대로 적용합니다. 2026년 8월에는 운영 중인 사이트의 학비 정보 38건을 대학 공식 페이지와 전수 대조해 표 오류를 바로잡았습니다. 당시 작업 커밋도 공개되어 있습니다.

  • 수치·요건은 원출처(공식 페이지)와 대조한다
  • 숫자와 날짜는 이중으로 확인한다
  • 배포·제출까지 끝내야 완료로 친다
  • 샘플만 보지 않고, 발행 전 결과물을 한 건씩 끝까지 본다

넓히는 만큼 경계도 같이 긋습니다. 실제 값 치환, 승인 계정만 사용, 내부 자료 업로드 금지 같은 수칙은 가이드의 보안 수칙 절에 정리해 두었습니다.
