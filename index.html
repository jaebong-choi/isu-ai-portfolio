자동화 실적

유학 기업 재직 중 실무로 만든 자동화입니다. 행을 누르면 검증 방법이 열립니다.

자동화 대상사용 도구Before → After절감 효과
인스타 카드뉴스(1080×1350) 세트 제작 Claude 스킬 + Python/Playwright (HTML→PNG 렌더링) Before → After수작업 3~4시간 → 1시간 절감세트당 2~3시간

검증: 발행 전에 수치와 날짜를 원문과 대조하고 렌더링 결과를 전수 확인합니다. 비자·정책 뉴스를 카드뉴스로 만드는 작업은 스킬로 고정해 두었습니다. 브랜드 색과 레이아웃 규칙을 스킬에 담아 HTML로 조판한 뒤 Playwright로 렌더링합니다.

국가별 유학 안내 사이트 데이터 구축·배포 Claude Cowork (조사·교차검증) + Claude Code (구현) Before → After수작업 3일 → 4~5시간 절감사이트 5종 배포 완주

검증: 수집한 진학 요건과 학비 데이터를 각 대학 공식 페이지와 대조해 확인한 뒤 반영했습니다. Cowork로 조사하고 Claude Code로 구현해 GitHub Pages에 배포했습니다. 미국, 영국, 호주, 캐나다 진단 사이트에 허브까지 5종입니다.

네이버 블로그 원고 생산 (검수 포함) Claude 스킬 (SEO 구조화 + 문체 검수) Before → After편당 2~3시간 → 30분 절감편당 약 2시간

검증: 인용하는 수치는 출처 페이지에서 직접 확인하고, AI 문형을 걸러내는 검수 단계를 거쳐 발행합니다. 네이버 SEO 구조와 문체 규칙을 스킬로 만들어 초안을 뽑습니다.

쇼츠용 9:16 데이터 그래픽 제작 Claude 스킬 + Playwright 렌더링 Before → After컷당 2~3시간 → 30분 절감컷당 약 2시간

검증: 수치는 대본의 출처와 대조한 뒤 렌더링합니다. 쇼츠 대본의 화면 지시를 표와 그래프, 타임라인 카드(1080×1920)로 바꾸면서 서술형 정보를 데이터 그래픽으로 재구성합니다.

출국 전 오리엔테이션 반복 안내 Notion 시스템 (영국·캐나다·호주 3개국) Before → After구두 안내 1시간/건 → 셀프 안내 절감건당 40분

검증: 학생이 스스로 읽고 확인 사항만 상담으로 남겨, 건당 확인 시간은 20분 수준으로 줄었습니다. 상담원이 매번 1시간씩 구두로 반복하던 출국 전 안내를 국가별 Notion 문서 체계로 코드 없이 표준화해, 안내 누락을 구조적으로 방지합니다.

공정 실적 자동 리포트 (데모)
데모 페이지 → 웹 데모 (브라우저에서 엑셀 파싱) Before → After수작업 주간 집계 → 자동 리포트 절감가상 2주치 실적 → 리포트 1건

검증: 이상치 판정 기준을 페이지에 그대로 적어 두어, 표시된 값은 누구든 손으로 재검산할 수 있습니다. 가상의 공정 실적 엑셀(라인별 생산량·수율·불량 유형)을 올리면 주간 요약과 이상치 하이라이트를 만들어 주는 데모입니다. 샘플 데이터는 전부 가상입니다.

검증·품질 습관

AI가 만든 결과물도 검증은 사람이 합니다.

유학 수속 실무에서 지원 서류나 비자 서류처럼 오류 하나가 결과를 바꾸는 문서를, 건별 마감 일정과 체크리스트로 관리해 왔습니다. 그 기준을 AI 산출물에도 그대로 적용합니다. 2026년 8월에는 영국 진단 사이트의 학비 정보 38건을 대학 공식 페이지와 전수 대조해 표 하한 오류를 바로잡았습니다.

  • 수치·요건은 원출처(공식 페이지)와 대조한다
  • 숫자와 날짜는 이중으로 확인한다
  • 배포·제출까지 끝내야 완료로 친다
  • 샘플만 보지 않고, 발행 전 결과물을 한 건씩 끝까지 본다
